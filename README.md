# Страница ссылок для TikTok

Статичная страница `index.html` + несколько функций в `api/`. Сборка и npm-пакеты не нужны.

## Как залить на Vercel

**Вариант 1. Через терминал (быстрее всего)**

```bash
npm i -g vercel
cd ~/tt-traffic
vercel --prod
```

Vercel спросит пару вопросов: на всё жми Enter. В конце покажет ссылку вида `https://tt-traffic.vercel.app`.

**Вариант 2. Через сайт**

1. Залей папку в репозиторий на GitHub.
2. На vercel.com → Add New → Project → выбери репозиторий → Deploy.
   Framework Preset: «Other», остальное не трогай.

## Что поменять под себя

Всё в `index.html`:

- **Имя и описание**: блок `<header>` (`<h1>` и `.bio`).
- **Аватар**: положи `avatar.jpg` рядом с `index.html` и замени `<span>😎</span>` на `<img src="avatar.jpg" alt="">`.
- **Тексты кнопок**: `.title` и `.sub` внутри каждой ссылки.
- **Новая ссылка**: скопируй один блок `<a class="link ...">…</a>` и поменяй `href`, иконку и тексты.
- **Плашка «ТОП»**: `<span class="badge">` и класс `featured` у главной ссылки.

## Ссылка на сайт по странам

Кнопка «Мой любимый сайт» видна не всем. Страну посетителя Vercel определяет по IP:

| Страна | Что видит |
|---|---|
| Беларусь (BY) | кнопку со ссылкой `lksi.pro/461612` |
| Россия (RU) | кнопку со ссылкой `lkdq.cc/e39c` |
| Украина (UA) | кнопку со ссылкой `lkan.pro/c010c1` |
| Узбекистан (UZ) | кнопку со ссылкой `lkmv.cc/c5208044` |
| Остальные | только VPN |

Ссылки лежат в `api/links.js`, в объекте `SITE_BY_COUNTRY`. Чтобы добавить страну, допиши строку,
например `KZ: 'https://...'`. Самих ссылок в HTML нет, поэтому посетитель из другой страны
не найдёт их даже в коде страницы.

Учти: если человек сидит под VPN, страна определится по VPN-серверу.

## Статистика

### Своя страница `/stats` (заходы и клики по кнопкам, бесплатно)

Открой `https://<твой-сайт>.vercel.app/stats` и введи пароль. Там видно:

- сколько людей зашло на страницу (уникальные и все открытия);
- сколько человек кликнуло на VPN и на сайт и какой это процент от зашедших;
- разбивку по странам и по дням (за сегодня, 7, 30 или 90 дней).

Боты и превью ссылок (Telegram, поисковики) не считаются. Сутки считаются по Минску/Москве.

**Настройка (один раз):**

1. **База.** Vercel → проект → **Storage** → **Create Database** → **Upstash** (Redis) →
   бесплатный план → **Connect** к проекту `tt-traffic`. Vercel сам добавит переменные
   `KV_REST_API_URL` и `KV_REST_API_TOKEN`.
2. **Пароль.** Vercel → проект → **Settings** → **Environment Variables** → добавь
   `STATS_PASSWORD` = любой придуманный пароль.
3. **Redeploy.** Вкладка **Deployments** → у последнего деплоя «⋯» → **Redeploy**
   (переменные подхватываются только после нового деплоя).

Пока база не подключена, сайт работает как обычно, просто клики никуда не пишутся.

Как это устроено: `api/links.js` считает заход (страница вызывает его при каждом открытии),
`api/click.js` считает клик, `api/stats.js` отдаёт цифры, `stats.html` их показывает.
Общий код лежит в `api/_lib.js`.

### Vercel Analytics

Project → Analytics. Там посещения, страны, источники и устройства.
Клики по кнопкам (`click_vpn`, `click_site`) Vercel показывает только на тарифе Pro,
поэтому их смотри на `/stats`.
