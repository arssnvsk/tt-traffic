# Страница ссылок для TikTok

Статичная страница: `index.html` + `vercel.json`. Сборка не нужна.

## Как залить на Vercel

**Вариант 1. Через терминал (быстрее всего)**

```bash
npm i -g vercel
cd ~/tt-traffic
vercel --prod
```

Vercel спросит пару вопросов: на всё жми Enter. В конце покажет ссылку вида `https://tt-traffic.vercel.app`.

**Вариант 2. Через сайт**

1. Залей папку в репозиторий на GitHub.
2. На vercel.com → Add New → Project → выбери репозиторий → Deploy.
   Framework Preset: «Other», остальное не трогай.

## Что поменять под себя

Всё в `index.html`:

- **Имя и описание**: блок `<header>` (`<h1>` и `.bio`).
- **Аватар**: положи `avatar.jpg` рядом с `index.html` и замени `<span>😎</span>` на `<img src="avatar.jpg" alt="">`.
- **Тексты кнопок**: `.title` и `.sub` внутри каждой ссылки.
- **Новая ссылка**: скопируй один блок `<a class="link ...">…</a>` и поменяй `href`, иконку и тексты.
- **Плашка «ТОП»**: `<span class="badge">` и класс `featured` у главной ссылки.

## Ссылка на сайт по странам

Кнопка «Мой любимый сайт» видна не всем. Страну посетителя Vercel определяет по IP:

| Страна | Что видит |
|---|---|
| Беларусь (BY) | кнопку со ссылкой `lksi.pro/461612` |
| Россия (RU) | кнопку со ссылкой `lkdq.cc/e39c` |
| Украина (UA) | кнопку со ссылкой `lkan.pro/c010c1` |
| Узбекистан (UZ) | кнопку со ссылкой `lkmv.cc/c5208044` |
| Остальные | только VPN |

Ссылки лежат в `api/links.js`, в объекте `SITE_BY_COUNTRY`. Чтобы добавить страну, допиши строку,
например `KZ: 'https://...'`. Самих ссылок в HTML нет, поэтому посетитель из другой страны
не найдёт их даже в коде страницы.

Учти: если человек сидит под VPN, страна определится по VPN-серверу.

## Статистика

На Vercel: Project → Analytics → Enable. Будут видны посещения и источники.
Клики по каждой кнопке (`click_vpn`, `click_site`) отображаются в Custom Events (это на платном тарифе Pro).
